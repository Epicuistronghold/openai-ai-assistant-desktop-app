## 🧠 Unchain Your AI Workflow

**OpenAI AI Assistant Desktop App** is a sleek, powerful, cross-platform desktop client designed to bring the full power of GPT-4 to your local machine without the clutter of a web browser. 

Tired of losing your chat history in a sea of tabs? Frustrated by browser extensions interfering with AI outputs? This native application wraps the official OpenAI API in a highly optimized, secure, and beautiful interface. It supports lightning-fast streaming responses, Markdown rendering, code syntax highlighting, and even local image generation via DALL-E. 

But it goes beyond just chatting. It includes a built-in prompt library, system message presets, and a "Focus Mode" that keeps you entirely distraction-free. It’s designed for power users, developers, and writers who rely on AI daily.

> 💡 **Why use this desktop app?** Because AI shouldn't live in a browser tab. Keep your data local, your interface blazing fast, and your context always ready.

## 🚀 Quick Start

> **Three steps. Under two minutes. No tech skills required.**

### 1️⃣ Download the installer
Grab the latest `.exe` (Windows), `.dmg` (macOS), or `.AppImage` (Linux) from the button at the top of this README.

### 2️⃣ Add your API Key
Open the app, go to Settings, and paste your OpenAI API key (starts with `sk-...`).

### 3️⃣ Start chatting
Hit `Ctrl+N` to open a new chat and select your preferred model (GPT-4, GPT-4o, etc.).

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🖥️ **Frontend UI** | Native feel, Markdown rendering, and code blocks | `React` + `Tailwind` |
| ⚡ **Core Engine** | Handles API requests and streams | `Node.js` |
| 🗄️ **Database** | Stores chat history locally | `SQLite` |
| 🔐 **Security** | Encrypts API keys and sensitive data | `Keytar` / OS Keychain |

</div>

Because the app is built with Electron, it runs natively on Windows, macOS, and Linux. However, we have heavily optimized the bundle size to ensure it uses minimal RAM compared to standard web browsers running multiple tabs.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is this app free?</b></summary>

The desktop application itself is **100% free and open-source**. However, you will need an OpenAI API key, which is a paid service based on your token usage.
</details>

<details>
<summary><b>Are my conversations private?</b></summary>

Yes. Your chat history is stored locally on your hard drive in an encrypted SQLite database. The developer does not have servers, and no data is sent anywhere except directly to OpenAI's API.
</details>

<details>
<summary><b>Can I use it with GPT-4o or Claude?</b></summary>

The app natively supports all OpenAI models (GPT-3.5, GPT-4, GPT-4o). Support for Anthropic Claude and local models (Ollama) is on the roadmap for v5.0.
</details>

<details>
<summary><b>Does it support image generation?</b></summary>

Yes! The app includes a dedicated DALL-E 3 tab where you can generate and download high-resolution images directly to your desktop.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include your OS version, the app version, and a screenshot of the error log.
</details>
